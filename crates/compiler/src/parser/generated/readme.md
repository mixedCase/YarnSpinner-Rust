# ANTLR files

All files in this directory were autogenerated by ANTLR. Don't edit them by hand.

## Autogeneration

- Download [the ANTLR tool of antlr4rust](https://github.com/antlr4rust/antlr4/releases/tag/v0.5.0)
  (`antlr4-4.13.3-SNAPSHOT-complete.jar`). You also need `java`.
- Download the third-party submodules: `git submodule update --init --recursive`
- Run `ANTLR_JAR=path/to/antlr4-4.13.3-SNAPSHOT-complete.jar ./scripts/generate-parser.sh` in the root of this repo.

The script generates the lexer and parser from `third-party/YarnSpinner/YarnSpinner.Compiler/Grammars/*.g4`
and then applies the adjustments that the generated code needs:

- Rename `YarnSpinnerParserParserContext` to `YarnSpinnerParserContext`: the generator emits the wrong trait name
  for rules with labelled alternatives.
- Replace `visitor.visit_node(self);` by `YarnSpinnerParserVisitor::visit_node(visitor, self);`. `node` is a rule
  of the grammar, so the call is ambiguous with the `visit_node` of ANTLR and recurses forever otherwise.
- Route the semantic predicates and actions of the lexer (`IsInWhenClause`, `SetInWhenClause`,
  `IsEndOfCommandKeyword`) to `crate::parser::lexer_support`. In the C# implementation, they are members of the
  lexer base class.

The generated modules are listed in `generated.rs`, with lint allow attributes for `warnings`, `clippy` and `rustfmt`.
